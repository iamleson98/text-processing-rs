# Vietnamese ITN cardinal test cases (spoken → written).
# Each line: spoken_form~written_form
# Note: single-scale expressions like "một triệu" / "một tỷ" are preserved by
# the decimal tagger ("1 triệu" / "1 tỷ"). Only compound multi-scale expressions
# (e.g. "hai tỷ ba triệu bốn nghìn năm") are folded to digits by the cardinal.

# === Basic 0-19 ===
mười~10
mười một~11
mười lăm~15
mười chín~19

# === Tens 20-99 (mốt/lăm positional variants) ===

hai mươi chín~29
ba mươi~30
ba mươi mốt~31
bốn mươi hai~42
chín mươi chín~99

# === Hundreds 100-999 (linh linker, lẻ variant) ===

chín trăm chín mươi chín~999
một trăm linh không~100

# === Thousands (nghìn Northern, ngàn Southern) ===

# === Millions and billions (single-scale preserved by decimal tagger) ===

# === Composed scales (10^12, 10^15, 10^18) ===
một tỷ tỷ~1000000000000000000

# === Multi-scale compound (folded to digits) ===
